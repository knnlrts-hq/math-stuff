The Self-Reference Machine

How can a formula talk about itself? Through a brilliant substitution trick.

Gödel constructed a formula G that essentially says: "This formula is not provable."

If G is provable, then it's false (contradiction). If G is not provable, then it's true but unprovable.

1

Start with a formula containing variable y

Consider: (x)∼Dem(x, sub(y, 13, y))

"For all x: x is not a proof of the formula obtained by substituting into the formula with Gödel number y"

(x)∼Dem(x, sub(y, 13, y))
2

Calculate its Gödel number

This formula has a Gödel number. Call it n.

n is astronomically large, but it exists and is uniquely determined.

3

Substitute n for y

Replace every y with the numeral for n:

(x)∼Dem(x, sub(n, 13, n))

This new formula is called G.

4

The magic: G's Gödel number IS sub(n, 13, n)

By construction, G was made by substituting n into the formula with Gödel number n.

So G's own Gödel number is exactly sub(n, 13, n).

5

G talks about itself!

G says: "The formula with Gödel number sub(n, 13, n) is not provable."

But that formula is G itself.

G says: "G is not provable"
Step 1 of 5

The Conclusion

If G is provable...

Then what G says is false.
G says "G is not provable" — so G would be both provable AND not provable. Contradiction.

If G is not provable...

Then what G says is true.
G is a true statement that cannot be proven within the system. Arithmetic is incomplete.

Key insight: Before Gödel, mathematicians hoped the blue circle could eventually encompass the green circle — that all truths could be derived from axioms. Gödel proved this is impossible.

What happens if we add G as an axiom?

Original System

G is true but unprovable
The system is incomplete — there exist truths it cannot reach.

Extended System (with G as axiom)

G is now provable (trivially)
But now we can construct G' — a new true-but-unprovable statement. The gap can never be closed.

Essential incompleteness: No matter how many axioms we add, there will always be true arithmetical statements that cannot be proven. This is not a flaw to be fixed — it's a fundamental feature of sufficiently powerful formal systems.

The Three Regions

Axioms

The starting points. Accepted without proof. In arithmetic: properties of 0, successor, addition, multiplication.

Provable Theorems

Everything derivable from axioms using rules of inference. What a computer could (in principle) verify.

All Truths

Everything that's actually true about numbers. Gödel showed this is strictly larger than what's provable.

The Paradox Genealogy

Gödel's construction is inspired by ancient paradoxes — but carefully avoids their contradictions.

The Liar Paradox

"This sentence is false."
If true, then it's false. If false, then it's true. Immediate contradiction — the sentence is meaningless.

The Richard Paradox

"The smallest number not definable in under 100 characters."
That description itself is under 100 characters! Contradiction from mixing language levels.

Gödel's G

"This formula is not provable."
No contradiction! G is simply true and unprovable. "Unprovable" ≠ "false".

Why Gödel Succeeds Where Others Fail

Paradox Self-Reference About Outcome
Liar Truth/Falsity Contradiction (meaningless)
Richard Definability Contradiction (level confusion)
Gödel Provability No contradiction — just incompleteness

The crucial distinction: "False" and "unprovable" are not the same thing. A statement can be true without being provable. Gödel's construction exploits this gap.

The Richard Paradox in Detail

1

List all English definitions of numbers

"The year of the Declaration of Independence" → 1776

"One plus one" → 2

2

Order them and define "Richardian"

The nth definition is "Richardian" if it does NOT define n.

3

Ask: Is "Richardian" Richardian?

If yes → it doesn't define its own position → no, it's not Richardian.

If no → it does define its own position → yes, it is Richardian.

Contradiction!

Gödel's escape: Instead of talking about truth directly, G talks about provability within a formal system. The statement G is not inside the system judging itself — it's an arithmetical formula that encodes a claim about provability. The encoding (via Gödel numbers) keeps the levels separate.

Historical Context

Before 1931

Hilbert's Program aimed to prove all of mathematics consistent and complete using finite methods. The hope: every true statement could eventually be proven.

After 1931

Gödel showed this dream is impossible. Any consistent system powerful enough to express arithmetic is necessarily incomplete. Mathematics can never be fully captured by axioms.
